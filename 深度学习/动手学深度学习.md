## 2.1
**张量表示一个由数值组成的数组，这个数组可能有多个维度。 具有一个轴的张量对应数学上的_向量_（vector）； 具有两个轴的张量对应数学上的_矩阵_（matrix）； 具有两个轴以上的张量没有特殊的数学名称。**
1. 通过改变张量的形状，张量的大小不会改变。
2. 张量中的每个值都称为张量的 *元素*（element）
3. 对于任意具有相同形状的张量， 常见的标准算术运算符（`+`、`-`、`*`、`/`和`**`）都可以被升级为按元素运算。

### 2.1.3
- _广播机制_ :
    1. 通过适当复制元素来扩展一个或两个数组，以便在转换之后，两个张量具有相同的形状；
    2. 对生成的数组执行按元素操作。
### 2.1.7
- 深度学习存储和操作数据的主要接口是张量（维数组）。它提供了各种功能，包括基本数学运算、广播、索引、切片、内存节省和转换其他Python对象。

# 三、线性神经网络
## 3.1、线性回归
- 在自然科学和社会科学领域，_回归_（regression）经常用来表示输入和输出之间的关系。
- 在机器学习领域中的大多数任务通常都与_预测_（prediction）有关。 当我们想预测一个数值时，就会涉及到回归问题。但不是所有的_预测_都是回归问题。
- _权重_（weight）决定了每个特征对我们预测值的影响。
- 偏置是指当所有特征都取值为0时，预测值应该为多少。

> [!NOTE]
> - 而在机器学习领域，我们通常使用的是高维数据集，建模时采用线性代数表示法会比较方便。当我们的输入包含d个特征时，我们将预测结果$\hat{y}$（通常使用 “尖角” 符号表示y的估计值）表示为：
$\hat{y} = w_1 x_1 + ... + w_d x_d + b. \tag{3.12}$
- _损失函数_（loss function）能够量化目标的_实际_值与_预测_值之间的差距。
- 更难做到的是找到一组参数，这组参数能够在我们从未见过的数据上实现较低的损失， 这一挑战被称为_泛化_（generalization）。
- ==给定特征估计目标的过程通常称为_预测_（prediction）或_推断_（inference）。==
- 由于模型重点在发生计算的地方，所以通常我们在**计算层数时不考虑输入层。**
- 对于线性回归，每个输入都与每个输出相连， 我们将这种变换（ [图3.1.2](https://zh.d2l.ai/chapter_linear-networks/linear-regression.html#fig-single-neuron)中的输出层） 称为_全连接层_（fully-connected layer）或称为_稠密层_（dense layer）。

## 3.3 线性回归的简洁实现
- batch_size是每个批次的数据量 = 一次喂多少数据=批次大小
-  `Sequential`类将多个层串联在一起。 当给定输入数据时，`Sequential`实例将数据传入到第一层， 然后将第一层的输出作为第二层的输入，以此类推。
- L1 求和绝对值，L2 平方再开根
   - **L1 范数**：绝对值之和 → 曼哈顿距离
   - **L2 范数**：平方和开根号 → 欧式距离
- lr是学习率（*learning rate*）
- is_train是一个布尔值，指示是否为训练模式


## 3.4 softmax回归
- _独热编码_（one-hot encoding）是一个向量，它的分量和类别一样多。 类别对应的分量设置为1，其他所有分量设置为0。
- 与线性回归一样，**softmax回归也是一个单层神经网络**。
- 尽管softmax是一个非线性函数，但softmax回归的输出仍然由输入特征的仿射变换决定。 因此，softmax回归是一个_线性模型_（linear model）。

## 3.5  图像分类数据集
- Fashion-MNIST由10个类别的图像组成， 每个类别由_训练数据集_（train dataset）中的6000张图像 和_测试数据集_（test dataset）中的1000张图像组成。 因此，训练集和测试集分别包含60000和10000张图像。 测试数据集不会用于训练，只用于评估模型性能。


## 3.7. softmax回归的简洁实现

- API = 应用程序编程接口
```
net = nn.Sequential(nn.Flatten(), nn.Linear(784, 10))
# 我们在线性层前定义了展平层（flatten），来调整网络输入的形状
# nn.Flatten()会把 28×28 的二维图片，“拉平” 成一个长度为`28×28=784`的一维向量，作为全连接层的输入特征。
```
- softmax 函数：$y_j = \frac{\exp(o_j)}{\sum_{k} \exp(o_k)}$，其中 $y_j$ 是预测的概率分布，$o_j$是未规范化的预测的第 j 个元素。


# 四、多层感知机

## 4.1、多层感知机
-  最简单的深度网络称为_多层感知机_。多层感知机由多层神经元组成， 每一层与它的上一层相连，从中接收输入； 同时每一层也与它的下一层相连，影响当前层的神经元。
